ДелоPay 0.5 — демонстрационный PWA.
Загрузите index.html, manifest.webmanifest, sw.js и папку icons в КОРЕНЬ репозитория GitHub delopay. Не загружайте ZIP целиком.
GitHub: Settings > Pages > Deploy from a branch > main > /(root).
Новые возможности: поиск заданий по тексту и фильтр города для местных услуг.
Нет регистрации, общей базы пользователей, чата и реальных платежей. Данные локальны для браузера.
Если старая версия остаётся, обновите страницу Ctrl+F5; для PWA может потребоваться закрыть и открыть приложение.
